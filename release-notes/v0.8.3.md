## Fixed

- **Niri: a profile that turns a monitor off now really turns it off.**
  `niri msg output <name> on|off` (typically run by an idle or screen-off
  script) leaves a temporary override that wins over the config file until that
  output's block in the file changes. Re-applying a profile that disables the
  monitor left the block unchanged, so Niri kept the monitor on and the profile
  looked like it had reverted to the one with every monitor enabled. After
  writing the config, Monique now compares each connected output's live state
  with the profile and sends an explicit on/off action where they disagree,
  replacing any stale override. Outputs that already match are left alone.

## Changed

- **Release notes are read from `release-notes/v<version>.md`.** The release
  workflow used a single `RELEASE_NOTES.md` for every tag, so v0.8.1 and v0.8.2
  were first published with the v0.8.0 changelog (both have since been
  corrected).
