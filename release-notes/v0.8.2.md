## Highlights

A profile you pick yourself now stays in place: the daemon no longer switches back
to a "better" profile when a monitor you disabled drops into standby and reconnects.

## Fixed

- **The daemon respects the profile you chose for the connected monitors.**
  Disabling a monitor that is still plugged in (e.g. picking *LG+AOC* with a third
  monitor connected) sends it into standby: it drops out and comes back as
  connected-but-off. The daemon re-ran best match on that event, which ranks the
  profile with more external monitors enabled first, and flipped back to *Full*
  a few seconds later, turning the monitor on again.
- **AUR package:** added the missing `python-cairo` dependency.

## Changed

- **Explicit profile choices are remembered per monitor set.** A profile applied
  from the GUI or with `monique --switch-profile` is stored together with the
  monitors connected at that moment. Whenever exactly those monitors are
  connected, `moniqued` re-applies your choice instead of the automatic best
  match. A different set of monitors still uses best match, so recovery after a
  real standby drop is unchanged. Reverting in the GUI restores the previous
  choice; applying an unsaved layout or running `--detect-profile` clears it.
